# 1.5.1 三单同屏练习

按用户2026-10-31的新要求，修改下拉刷新找字反应测试页。

- 每轮恰好三张虚构订单；标准竖屏默认字体时三张卡片和各自滑条完整同屏，不再生成第四张。使用紧凑说明和卡片、缩短随机文案，并按可用高度分配空间；地址和目标字不得裁剪、隐藏或省略。
- 每轮恰有一个普通样式的田，只会在第一或第二张订单的地址中，作为路名等地址词的一部分。第三张、标题和备注都不出现田。两个目标位次均可随机产生。
- 下拉仍替换全部三张订单的标题、地址和备注，与上一轮不同；只按本人手动滑动计分，200ms复位和报告/导出保留。
- 报告目标位次比较对应第一和第二单。大字体、横屏或高度极小设备无法兼顾完整文字与同屏时，保留可读内容和滚动能力，不能通过裁掉地址让测试伪通过。

验证：先用失败的模型与设备回归锁定三单/地址/目标位次/同屏条件，再实现；500种子验证内容和唯一目标，默认及较窄竖屏实测可见范围、下拉刷新、计分/复位/报告和返回。独立Addy审查后构建、Lint、同签名发布并在模拟器覆盖升级。
