# 1.9.0 可抓取的贴边把手与拖出还原

用户反馈1.8.0的4dp细边过窄，且拖动后仍重新收起，难以像预期那样把完整浮窗拉出来。本版直接修正显示与手势状态转换。

- 收起把手改为20dp宽、所选32～120dp高度，显示朝屏幕内部的绿色箭头。收起时可见度至少35%，便于找到与抓住；菜单仍保存原10%～100%设置，展开恢复用户所选可见度，不覆写偏好。
- 从左把手向右、右把手向左，向内位移达到12dp且水平位移大于垂直位移时，在MOVE阶段展开完整电话浮窗。剩余拖动跟随手指，松手保持展开并停在当前位置，不立即重新折叠或强制吸回边缘。
- 展开时左侧保留手指距左边的抓取偏移，右侧保留距右边的偏移（展开增加的宽度向屏幕内侧生长），避免向内仅拉12dp时整块图标突然跑到屏幕外。
- 已展开浮窗可自由移动。只有向某侧边缘明显横向外推，且松手位置距该边不超过24dp，才收起到该侧；竖向移动或在屏幕中间松手保持展开。普通点击、三击、计时刷新和可见度变更不能改变位置。
- 点把手仍先展开，不切换开关或计入三击；展开后保持连续三击切换。拖动、多指和取消不能切换辅助。取消/无效多指操作恢复触摸前的展开/收起状态；原收起状态回到起始贴靠侧，竖向调整可保留安全位置。
- 大小调节保持折叠状态、选定尺寸、可见度与计时。展开的自由位置尽量保留并限制在屏幕内；本来正好贴边的完整浮窗调整尺寸仍保持该边。拖动期间真实服务不让轮询覆盖位置，也不应用新尺寸。
- 实际窗口、触摸和Back手势排除区域与当前可见范围一致，不保留大块不可见触摸区。API34+保留公开接口禁用状态窗移动动画；不改变目标前台/锁屏保护、一次人工触发规则及订单滑动逻辑。
