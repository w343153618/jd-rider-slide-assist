# 1.10.0 关键词提醒模拟

## 目标与范围

用户确认在本App的模拟抢单场景练习：下拉换一批6～8张虚构订单，南邮、南航、南理工随机出现或不出现；整批已加载数据（含屏幕外订单）都参与检查。命中后整页红色呼吸提醒，本人手动拖动抢单，不自动接受/筛选/滚动/刷新真实订单。

新增“关键词提醒模拟 · 手动抢单”模式入口，打开独立`KeywordTestActivity`，与已有自动辅助练习和手速/找字报告分开，避免开启提醒后误触旧辅助。新页全部滑条始终为手动模式，提醒开关只控制红色提醒，默认关闭。固定顶部提供返回、开关、命中状态与下拉提示，列表可滚动，控制按钮不随列表滚走。

本版检查App自身持有的文字数据，不调用截图/OCR或新增跨应用读取权限。真实京东屏幕外可读性和截图OCR的50/100ms延时尚未实测，不能由本版数据匹配成绩推断。后续适配须单独验收。

## 行为契约

- 每次下拉生成6～8单，标题、地址、货品和备注长短有变化，全部使用虚构内容；与上一批相同位置的四字段不同。三个简称独立随机出现/缺席，支持整批无匹配、多个学校和只有屏幕外订单匹配。以地址中的自然词出现，例如“南邮示例校区”。
- 匹配三个精确简称，任何订单字段命中均提醒。跨订单/字段不拼接文字制造命中。去重、按南邮/南航/南理工固定顺序列出本批命中；不将说明、控制面板、提示词或提醒状态当成订单数据再次匹配。
- 开启提醒后立即检查当前批；刷新提交新批时同步重新检查，无人为等待或轮询。无匹配立即停止红色层，匹配即安排下一绘制帧显示；列表滚动不影响整批匹配结论。停止提醒立即取消动画，清除红色层。
- 红色覆盖层不拦截触摸，不遮住文字至不可读，手动拖动和下拉继续可用。默认1200ms一个平滑呼吸周期（小于每秒一次），首次命中直接从较明显的22%红色开始，在4%～22%之间渐变，避免急促高频闪光。系统关闭动画时改为静态轻红提示。
- 未开启、离开/后台/停止以及分离窗口时不运行呼吸动画；重复命中不反复创建动画或重置周期。返回恢复前台时按本页开关和当前批重新计算。旋转保留提醒开关与当前批，进程重建至少恢复对应种子和开关，不伪称保留硬件帧历史。
- 页面只做本地模拟，不启动真实辅助、不派发系统滑动、不隐式开启记录；普通点击滑条不能自动完成，必须从白色手柄手动拖到终点，原200ms复位规则保留。

## 模块与实现顺序

1. `KeywordMatcher`：纯Java精确匹配及不可变结果。
2. `KeywordOrderGenerator`：可重现种子的6～8单本地生成器与新批差异约束。
3. `RedBreathingView`：无触摸拦截的可清理动画层。
4. `KeywordTestActivity`：固定控件、下拉列表、整批匹配、手动滑条及生命周期；Main只增加入口，已有Main辅助行为保留。
5. 主机/原生/实际手动拖动及升级验收，同签名1.10.0/code14发布，旧版本保留。

## 栈、命令和风格

原生Java，现有SDK35/min24、Gradle包装器及AGP配置，无运行时新依赖。代码放`app/src/main/java/com/example/slideassist`，纯测试在`tests`，设备测试在`app/src/androidTest`，证据在`docs`，私有日志/图片仍在忽略的`artifacts`。

```sh
tests/run-unit-tests.sh
tests/run-update-policy-tests.sh
./gradlew :app:assembleDebug :app:assembleRelease :app:assembleFixtureCheck :app:assembleFixtureCheckAndroidTest :app:lintDebug :app:lintRelease --offline
adb shell am instrument -w -e v110keyword 1 com.example.slideassist.testfixture.test/com.example.slideassist.GestureInstrumentation
```

保持现有简单final类、缓存绘图对象、状态变化同步更新以及有界列表风格；示例：`List<String> hits = KeywordMatcher.matchFragments(texts);`。滑条复用真正无自动补齐动画的`ManualSpeedSliderView`，从白色手柄手动拖过98%并抬手才完成。不为了测试添加真实客户端包替换入口或生产调试按钮。

## 验收和边界

先用旧Main缺失入口的原生RED及缺少匹配/生成器的主机RED证明新行为缺失，再实现。主机覆盖500种子、6～8单、全无/全有/末尾命中、字段变更、去重和跨字段不拼接。原生测试用种子控制本批，独立计算期望，检查屏幕外单独命中、无匹配停止、自身提示不误触发、手动点击/拖动、覆盖层触摸穿透、下拉换批、暂停/恢复/返回/旋转、动画禁用与周期清理。

始终运行相关回归并由作者之外的Addy五轴审查；不删除失败断言以获得通过，不上传客户数据、截图、日志或密钥。新增真实跨应用读取、录屏/OCR或自动订单动作均不属于本版，不能用模拟页通过来宣称真实京东兼容或50/100ms性能达标。
