# 1.8.0 浮窗贴边收起

用户报告1.7.0仅把完整电话浮窗对齐左右边缘，没有像期望的那样收进边缘，只留一条窄缝。

- 模拟页和真实辅助窗口：拖动松手后吸附最近的物理左右边缘，并收起为4dp宽的竖向窄边，高度保持所选32～120dp尺寸。初次显示仍为完整电话浮窗。
- 点一下收起的窄边先展开，保留原来停靠侧和垂直位置；这次点击不改变辅助开关，也不计入展开后的三击序列。展开后仍必须连续三击才切换开关。也能从窄边拖出并松手重新贴边收起。
- 取消触摸或多指无效操作不触发开关，取消保留触摸前的展开/收起状态；拖动和展开清空连击。隐藏只改变控件表现，不隐藏无障碍服务或改变订单触发约束。
- 大小和可见度调整保留收起状态。展开时电话和计时按原尺寸显示，收起时只绘制窄边，实际窗口宽度/触摸范围/系统手势排除范围都只有4dp，不保留不可见的大块拦截区。
- 收起/展开必须复用同一个View，开启计时持续运行；收起、展开、调整大小或状态轮询不能清零。无障碍描述提供真实辅助状态及展开提示。
- 真实页仍受目标前台、锁屏、执行中隐藏、一次人工触发最多一次滑动等规则约束。原三单练习、手速报告、200ms复位、档位和音量快捷键保留。
- 用户追加：应用名称及首页标题改为“大爷骑火箭”，使用原创可爱小火箭桌面图标，兼容旧式及自适应图标裁切。包名、更新仓库和正式签名保持，以便现有安装覆盖升级；测试夹具名称带明确测试标识。

实现采用屏幕内的窄窗口而非依赖负坐标超出屏幕，避免WindowManager把完整窗口重新夹回屏幕内。先记录旧版拖动后仍为完整64dp宽的原生失败，再实现；验证左右两侧、点窄边展开、三击隔离、最小/最大尺寸、计时/透明度、取消/多指以及实际全局边缘触摸。按Addy独立审查、构建和设备回归后，同签名发布1.8.0/code12，保留旧版本，验证应用内升级。

全局触摸检查发现Android系统默认窗口移动动画可持续400ms，在此期间视觉窄边还在移动。API34及以上通过公开`setCanPlayMoveAnimation(false)`让状态窗口即时移动，避免立即点击屏幕边缘时错过动画中的窗口。低于API34保留系统行为，不通过隐藏接口绕过系统限制；截图及全局检查须核实实际显示位置，不能只依据LayoutParams。
