# 1.7.0 可调大小的电话浮窗

用户要求把1.6.0的电话浮窗放大至接近微信后台语音通话浮窗的观感，并增加大小滑杆。没有提供对应微信版本截图，采用黑底圆角方窗、绿色听筒、下方计时的自绘样式，不声称逐像素一致；它始终表示本工具的辅助状态。

- 默认64×64dp，菜单增加“浮标大小”滑杆，32～120dp逐dp调整，实时预览并持久保存；模拟页和真实辅助服务共用。老版本没有此设置时使用64dp。保留独立的10%～100%可见度，默认10%。
- 电话、计时字号、内边距与圆角随实际控件尺寸缩放。开启时显示持续递增计时，关闭时只显示电话；调整大小、透明度、反复刷新不能重置计时。
- 改大小时保持原来贴靠的左右边缘，垂直位置限定在可用范围。最小、默认、最大尺寸均支持拖动贴边、连续三击切换；单击/双击不切换，拖动/取消清空三击序列。系统返回手势排除区域只覆盖浮窗自身。真实服务正在拖动时延后应用尺寸变化，防止手下跳动。
- 三单找字页、田字仅在前两单地址、手动测速/报告、200ms复位、模拟时长档位、音量开关和真实服务一次人工触发约束保持。

验收：先添加尺寸归一化、菜单和实际服务窗口回归；验证32/64/120dp、持久化、两侧吸附、计时不归零、透明度独立及三击。完成主机回归、Android原生设备测试、构建/Lint和Addy独立审查。以同一正式签名发布1.7.0/code11，保留旧版本，并验证正式1.6.0经应用内更新安装到1.7.0。模拟器证据与真实京东/实体手机验收分开记录。
