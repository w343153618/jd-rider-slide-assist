# 大爷骑火箭

面向 **京东秒送骑士（原达达快送骑士）** 的 Android 手动滑动辅助适配测试版。适合先在虚构订单中练习，再在自己的设备上验证触控辅助效果。

本项目独立开发，与京东/达达不存在官方合作或授权关系。兼容特定客户端名称不代表平台许可，也不保证实际接单成功或不会触发风控。

## 已实现

- 固定目标应用 `com.dada.mobile.android`，显示安装状态与版本；普通版本不允许切换为其他目标。
- 主动开启辅助后直接打开骑士应用；自行把半透明区域对齐当前订单滑条。
- 在骑士页面同时短按音量加、减键，切换辅助开关。快捷键只开关辅助区，开启后仍需本人触发滑动。
- 骑士页面贴边显示电话浮窗：默认64×64dp黑色圆角方框、绿色电话，开启时下方正向计时，关闭时只显示电话；连续轻点三次切换，单击/双击不切换，拖动松手后收进最近左右边缘，仅留4dp窄边；点窄边先展开，该点击不改变开关、不计入三击。收起时计时继续，实际触摸范围也只有窄边宽度。首页“浮标设置”可用大小滑杆在32～120dp调节，并独立调整10%～100%可见度（默认10%）；即时生效并保存，模拟页与真实页共用。调整大小保持贴边且不重置计时。离开目标或锁屏时隐藏。模拟页也提供状态球和音量快捷键练习。
- 三种可选触发方式：按下即执行；最初的手指抬起后执行；单指双击或双指轻点。
- 真实辅助时长保留100、150、200、250、450、700毫秒；模拟页独立增加50、60、70、80、90毫秒，共11档，默认250毫秒。手动测速不使用这些自动时长。
- 只有起点落在左侧白色双箭头手柄内部才触发；橙色其他位置和外起手移入不触发。从手指最初按下坐标开始向右移动完整行程，保持Y与抓取偏移。真实页面每次手动触发至多派发一次滑动，结束即关闭，无自动重试。
- 六张文字长短不同的虚构订单，可上下滚动，每次操作结束且手指全部抬起后200ms自动复位，保留完成次数。
- 模拟页在完成订单后保持辅助开关，可继续点击其他订单；同一订单自动回位后可直接再练习。手动关闭状态球后停止点击辅助，重新开启后可继续。
- 派发前只允许指定应用前台；检测到切换窗口、滚动、锁屏或旋转后关闭并取消待派发动作。已经交给系统的手势无法保证中途撤销。
- 首页增加手速测试、轨迹图表/慢放回放及JSON/CSV本地导出，默认不采集，只有手动开始记录后采本工具可观察的数据。

应用不登录账号、不读取或保存真实订单内容，不自动找单、筛选或刷新真实订单。独立找字训练页只生成和保存虚构练习文字。仅在用户点击检查更新、下载时连接此项目的 GitHub 发布服务，不上传订单、按键记录或设备身份。它通过 Android 无障碍服务查询窗口的包信息、观察按键并派发手势；权限本身允许读取窗口内容，应按需开启。没有隐藏无障碍服务、随机轨迹或规避检测的功能。

## 安装与使用

适用 Android 7.0 及以上。自行构建的 debug APK 用于测试，尚非商店发行版本。

1. 安装本应用，先在模拟订单中比较触发方式。设置入口位于首页“展开设置”。
2. 确认手机安装的是官方京东秒送骑士，并核对本应用显示的版本。包名匹配不等于已校验发布者签名。
3. 在系统无障碍设置中开启“滑动辅助服务”，返回本应用，点击“启动辅助并打开骑士应用”。
4. 按住浮层标题移动，下方手柄调整宽高，使中间区域完整覆盖想操作的抢单滑条，左侧白色触发框与真实白色箭头块对齐。移动/调整手柄不会触发抢单；当前仍为人工对齐，不自动识别京东控件。
5. 确定要该订单后，再从白色箭头块内执行所选触发动作。手势结束后核对骑士 App 的实际结果；下一次重新启动并对齐。

在骑士页面可同时短按音量加、减键代替返回首页启动：两键按下间隔不超过200毫秒，来自同一设备，且手机已解锁。再次组合按键关闭辅助；两键都松开前只切换一次。其他应用前台不能用快捷键开启辅助。快捷键不能替代系统无障碍授权，也不会直接接单。

正常音量按键事件仍交由系统处理，音量可能改变；不要长按组合键，以免触发系统无障碍快捷方式。部分厂商系统或其他无障碍服务可能使该功能不可用，届时仍可用首页按钮。若设备漏报抬起导致组合键暂时失效，可熄屏再唤醒后重新尝试。更新后如按键不可用，可在系统设置中关闭再开启本服务，并核对按键权限说明。

**按下模式在触摸起点落入白色手柄时立即执行；抬起模式以最初的白色手柄内起点为准，即使移到区域外，首指抬起仍会触发。** 双击使用第二次按下坐标，双指轻点使用首指初次按下坐标。终点将白手柄向右平移完整可用行程，保持抓取偏移。抬起/手势模式尚未触发时收到系统取消事件，不执行；按下模式已经开始处理后，后续取消不保证撤销。浏览列表应从辅助区域外开始滚动。

辅助区域会截获其覆盖部分的触摸。页面在同一个窗口内更新时未必会发出可识别事件，必须在每次触发前核对当前订单与区域位置。点击浮层“关闭”或回到本应用“停止辅助”即可退出。

绿色电话浮标表示本工具的辅助开关，下方时间为已开启时长；不是微信通话或实际订单状态。真实辅助每次触发完成回到关闭态，下一单需再次开启并对齐。三次轻点相邻间隔不超过350毫秒、总计不超过800毫秒；移动、多指和取消会清掉连击。正在派发时状态球暂时隐藏，以免挡住滑动；若系统一直不报告手势结果，则保持停止状态，请先核对订单再重新开启无障碍服务。

## 手速与轨迹报告

1. 首页进入“手速测试与轨迹报告”，点击“开始新记录”。从白色手柄手动拖到右端并抬手；测试页完全不自动辅助。结束并抬手后200ms自动回位，可直接继续。顶部固定“返回模拟抢单”可随时返回。
2. 点击“停止并生成报告”，查看有效手动成功的最快、平均、中位、P95及成功率；选一次记录看等比轨迹、阶段时间轴、速度/采样间隔/应用接收滞后/pressure曲线和逐点表。
3. 回放支持0.1×/0.25×/0.5×/1×、播放暂停和拖动进度。光点仅按时间在原始点间做可视化插值，采样点不补造；实际操作时长和动画慢放时长分开。
4. JSON保留原始点与阶段，CSV为附上下文的逐点表。导出通过系统选择保存位置，不上传。数据只在本机进程内存中，退出进程会丢失，需要保留时先导出。

开始记录后也可返回首页练习或使用真实辅助，再回来停止生成报告。手动、模拟辅助、真实页辅助分列；辅助动画/系统回调耗时不会混入最快手速。只记录本工具触摸区域及辅助阶段，不全屏监听其他App。

原始点指Android交付的事件样本，可能已由系统重采样，不是触控芯片未处理数据。时间戳使用Android uptime，接收滞后包含事件批处理、排队和调度，不能当作屏幕硬件/京东服务器延迟；首次到达98%行程的采样时刻受触摸采样粒度影响，不代表光学测量的绝对手速。pressure、size、接触长短轴与角度仅为设备原始或估算读数；固定值不证明有真实压感，人体电流未提供。缺测显示未提供，JSON非有限值为null，CSV留空。

会话上限200次、每次1024点、总20000点及每次16阶段，超限、重复及乱序都显示计数；超过保存上限时图形和表格可能不完整，不会声称全部数据已保存。

## 找字反应测试

首页“找字反应测试 · 随机订单”进入独立手动测试页。点击“开始测试”后，每组只生成三张新虚构订单，标准竖屏默认字体下三单及滑条完整同屏。恰有一个普通样式的“田”，只随机出现在第一或第二单的地址路名中，例如“田园路”；第三单、标题和备注都不含“田”。找到目标后从其白色手柄手动向右拖到98%并抬手；每组仅首次正确完成计分。滑条200ms回位后可继续练习，但同组不重复计分。列表顶部下拉并松手会替换全部文字并开始新一轮；未完成轮次保留为放弃。

停止后报告提供各轮搜索、滑动和总耗时对比图，平均/中位/P95/最小/最大/总体标准差，前后最多五次成功的描述性比较，错单、重试、取消、外起手、滚动距离与方向改变，目标位次分组，等比轨迹及可慢放的动画回放、逐点表、原始pressure和路径回撤等指标。JSON包含完整已保存的虚构订单、种子、目标位置、尝试/阶段和原始点；CSV提供轮次对照表。每会话上限50轮/200次，原始点沿用既有上限；离开页面停止当前轮计时，旋转保留之前数据。顶部返回按钮始终可见。

“搜索”从应用呈现帧回调计到首次正确有效按下；“滑动”只计最终成功那次按下到首次98%；“总计”包含错单和失败重试，因此不保证搜索加滑动等于总计。目标字符首次可见仅按布局与视口相交估计，不是眼动/看见时间。前后窗口在不足十个成功时可能重叠；结果用于本地练习比较，不作为神经反应、硬件延迟或真实订单接受速度。

SHA 文件与 APK 同属一个发布来源，摘要用于校验传输完整性；应用签名与系统安装器检查共同约束发布者身份。支持同一签名的覆盖升级，不支持静默安装或任意换签名升级。早期1.1.0为 debug 测试包；首次换到正式签名包需卸载旧测试包再安装，练习设置会重置。之后的正式版本保持同一签名以保留设置升级。

发布者操作与签名保管见 [版本发布流程](docs/releasing.md)。

## 速度和验收范围

触发事件到达后立即启动处理；为等待浮层退出输入窗口，派发前确认视图已移除并等待两个显示帧，超过600毫秒则取消。滑动手势时长可选100/150/200/250/450/700毫秒，不增加触发前随机等待。更长时长意味着已派发手势可能继续运行的窗口更长。系统调度、手机触摸采样与目标 App 处理时间仍会影响实际响应。`dispatchGesture` 的完成回调只证明系统完成了手势，并不证明订单已被接受。

模拟页面、自有跨应用测试夹具、真实京东页面的验证结论分别见 [验证记录](docs/verification.md)。用户实际设备和真实订单页面尚待验收，不以模拟器测试代替。目标包名来源见 [客户端来源](docs/target-app.md)。

## 构建

需要 JDK 17或以上（本次使用21）、Android SDK Platform 35，以及能够下载 Gradle 和 Android Gradle Plugin 的网络环境。配置 `ANDROID_HOME` 或在未入库的 `local.properties` 中设置 `sdk.dir`。

```sh
./gradlew assembleDebug lintDebug
```

安装包：`app/build/outputs/apk/debug/app-debug.apk`。应用无运行时第三方依赖；构建依赖固定在 Gradle 配置及 wrapper 中。
